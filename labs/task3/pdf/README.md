# Завдання 3. Лінійна та нелінійна регресія

[Готовий звіт](output/pdf/Task_3_Final_Report.pdf) містить усі 15 обов'язкових
підпунктів задач 5 і 6. Обсяг: титул і 31 пронумерована сторінка, усі в портретній орієнтації.

Для кожного підпункту наведено умову, основний код із потрібним фактичним виводом
і результати та інтерпретацію. Спільну підготовку даних винесено на початок.
Залишено 15 основних лістингів, один спільний блок, 32 таблиці виводів і всі
9 рисунків на ширину тексту. Після ревізії скорочень усі таблиці й текстові виводи
вибраних клітинок показано повністю; єдине скорочення (історія 49 кроків відбору
за BIC) позначено приміткою «Скорочено» з переліком показаних і пропущених кроків.
Не показано лише одиничний блок матриці R у пункті 4. Лістинг пункту 3 наведено
повністю; решту лістингів обрамлено коментарями про код, який у звіт не ввійшов.
Службовий вступ, заголовок виводів, повторні таблиці в поясненнях та технічний
розділ про структуру файлів із PDF вилучено. Жирні акценти всередині інтерпретацій
прибрано. Математичні результати й повні виконані notebook не змінено.

## Редагування та збирання

- [Основне джерело LaTeX](report/Task_3_Report.tex) визначає титул і оформлення.
- [Редакторський відбір](report_selection.py) визначає потрібні оператори коду,
  виводи, рядки та колонки таблиць. Фрагменти вибираються з AST виконаних клітинок разом із суміжними коментарями
  автора; шаблонні коментарі умови не переносяться.
- [Експортер](export_notebooks.py) формує `report/generated/` зі збережених notebook.
- [Компіляція](report/build.sh) збирає наявний LaTeX у готовий PDF.

З кореня репозиторію:

```sh
source .venv/bin/activate
python labs/task3/pdf/export_notebooks.py
sh labs/task3/pdf/report/build.sh
python labs/task3/pdf/validation/check_report.py
```

Notebook потрібно виконувати повторно лише після зміни розрахунків.
Скорочені лістинги є фрагментами розв'язку, а не окремими програмами: оформлення
графіків, службові перевірки та частина підготовчих змінних залишаються у повних
notebook. Усі показані оператори походять із фактично виконаного коду; виводи
читаються зі збережених результатів, а не генеруються заново. Імпорти бібліотек
у звіт не входять.

Експортер перезаписує автоматичні джерела в `report/generated/` і видаляє їхні
застарілі невикористані файли. Для зміни оформлення редагуйте основний LaTeX;
для зміни обсягу коду, виводів, приміток і рамкових коментарів — `report_selection.py`.

Потрібні Pandoc, Beautiful Soup, Pygments, XeLaTeX, latexmk і шрифти PT Serif,
PT Sans та Menlo. Контрольний скрипт використовує PyMuPDF. Маніфест експорту,
результати перевірок і нотатки візуального перегляду містяться в `validation/`.
