## Дані

[`input/AmesHousing.txt`](input/AmesHousing.txt) — повна версія Ames Housing
([De Cock, 2011](https://jse.amstat.org/v19n3/decock/AmesHousing.txt)):
2930 продажів, 82 колонки. Опис змінних — [DataDocumentation.txt](input/DataDocumentation.txt),
контрольні суми файлів — [checksums.json](input/checksums.json).
Файл читається з `keep_default_na=False, na_values=[""]`: структурні категорії
`NA` залишаються окремими рівнями, справжніми пропусками вважаються порожні клітинки.

## Задача 5: основні рішення

- Повна модель — `SalePrice` на всі пояснювальні змінні, крім ідентифікаторів,
  `GarageYrBlt` (не існує без гаража) та точних сум площ `TotalBsmtSF`, `GrLivArea`.
  Категорії — фіктивні змінні з найчастішим рівнем як базою.
- Регресії пунктів 4–8, 10–11 — на 2414 повних спостереженнях; пункт 3 — на всіх
  2930; пункт 9 — на копії всього набору.
- Відбір змінних — власний зворотний покроковий алгоритм за BIC (29 із 75 змінних).
## Задача 6: основні рішення

- Перші 500 рядків (`df.iloc[:500]`) — це лише продажі 2009–2010 років, бо файл
  впорядковано за роком продажу; вибірка не випадкова.
- Нелінійна модель — `a * exp(b * (YearBuilt - 1970))` через `curve_fit`;
  початкові значення взято з регресії `log(SalePrice)` на рік.
- Пункти (в) і (г) підкріплено перевірками: формула `pcov` через лінеаризацію,
  збій збіжності без зсуву року, ранг матриці всіх змінних.
