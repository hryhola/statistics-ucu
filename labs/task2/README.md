## Робота з ноутбуками

Із кореня репозиторію:

```sh
source .venv/bin/activate
jupyter lab labs/task2/notebooks
```

Оберіть ядро **Python (.venv: statistics-ucu)**. Для повторного запуску всіх
п’яти ноутбуків у власних чистих ядрах:

```sh
python labs/task2/notebooks/run_notebooks.py
```

Кожен ноутбук працює незалежно. Підтримується запуск із кореня репозиторію,
`labs/task2/` та `labs/task2/notebooks/`. Для перенесення на інший комп’ютер
збережіть разом три каталоги `input/`, `notebooks/` і `pdf/`.
CSV читається з `input/`; результати й графіки записуються в `pdf/`.
PDF з умовою не потрібен для запуску розрахунків.
