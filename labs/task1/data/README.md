# Input data

`ceosal1.csv` is the unmodified data frame retrieved on 2026-10-01 through
`statsmodels.datasets.get_rdataset("ceosal1", "wooldridge")` from Rdatasets:
https://vincentarelbundock.github.io/Rdatasets/doc/wooldridge/ceosal1.html

The notebook uses this snapshot for reproducibility. Synthetic ages are generated
in memory with seed 42 and are not part of this source CSV.
