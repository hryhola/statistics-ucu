# Course repository rules

These rules apply to coursework maintained in this repository.

- Assignment descriptions, supplied notebook questions, and official course
  materials define the scope, methods, permitted libraries, and deliverables.
- Preserve supplied questions, scaffolding, random seeds, and required comments.
- Keep optional extensions separate from required work; record unattempted parts.
- Justify statistical claims, state assumptions, and distinguish exact results
  from approximations. Check units, indexing, and numerical limitations.
- Record predictions before experiments and retain them when results differ.
- Derive reported values from actual outputs; do not invent results or execution.
- Preserve reference-solver restrictions. Keep implementation code readable and
  reproducible using the documented environment.
- Before submission, run required notebook cells in order from a fresh kernel,
  inspect plots, and keep saved outputs consistent with written answers.
- Record actual team contributions, completion, and verification accurately.
  Reading, implementation, execution, and understanding are distinct achievements.
- Follow the assignment's language, attribution, and assistance requirements.
- Preserve unrelated work and prepared deliverables. Review changes before
  committing, pushing, or submitting.
- Start added notebook answer text with `***Answer***`; leave original questions
  and code comments unchanged by this formatting rule.
