# Reference sources

Use these local sources for statistics, probability, and econometrics coursework.
Assignment requirements and official course materials take priority when choosing
methods and notation. PDF files in this folder and its subfolders are ignored by
Git and must be supplied locally after cloning.

## Books

- A Guide to Modern Econometrics, 5th Edition (Marno Verbeek).pdf
- Introduction to Probability Models, 10th Edition (Sheldon M. Ross).pdf
- Introductory Econometrics - A Modern Approach, 5th Edition (Jeffrey M. Wooldridge).pdf
- Mostly Harmless Econometrics - An Empiricist’s Companion (Joshua D. Angrist, Jörn-Steffen Pischke).pdf
- The Practice of Statistics, 6th Edition (Daren S. Starnes, Josh Tabor).pdf

## Official course materials

The `UCU/` subfolder contains lecture slides named `Lecture <number> – <topic>.pdf`:

- Lectures 1–3: descriptive statistics, probability, and statistical inference.
- Lectures 4, 5, and 5.1: linear regression and additional topics.
- Lectures 6.1–6.4: nonlinear and nonparametric regression, regularization,
  regression trees, resampling, and ensemble methods.
- Lectures 7.1–7.4: binary choice models, classification metrics and trees,
  nominal and ordinal models, and count data models.

The numbering preserves the original file identifiers; `5_1.pdf` is named
`Lecture 5.1` and covers the second set of additional linear regression topics.
